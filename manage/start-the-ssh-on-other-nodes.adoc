= Démarrer SSH sur les autres nœuds ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Avant de mettre à niveau ONTAP tools for VMware vSphere, vous devez démarrer SSH sur chacun des autres nœuds de votre environnement.

.Avant de commencer
Activez l'extension VASA Provider pour votre instance vCenter Server.

.Description de la tâche
Répétez cette procédure sur chaque nœud avant la mise à niveau.

.Étapes
. Connectez-vous au serveur vCenter.
. Localisez la machine virtuelle du nœud ONTAP tools et lancez la console Web.
. Connectez-vous en utilisant les `maint` identifiants.
. Entrez `4` Pour sélectionner support et Diagnostics.
. Entrez `1` Pour sélectionner accès au shell de diagnostic.
. Entrez `y` pour continuer.
. Exécutez la commande _sudo systemctl restart ssh_.
