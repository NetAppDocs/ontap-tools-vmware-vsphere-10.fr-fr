= Gérer les seuils de stockage dans ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez définir des seuils de stockage pour recevoir des notifications dans vCenter Server lorsque le volume ou la capacité agrégée atteint un certain niveau.

.Étapes
. Connectez-vous au client vSphere.
. Sur la page *Raccourcis*, sélectionnez *NetApp ONTAP tools* dans la section *Plug-ins*.
. Dans le volet gauche des outils ONTAP , accédez à *Paramètres* > *Paramètres de seuil* > *Modifier*.
. Dans la fenêtre *Modifier le seuil*, indiquez les valeurs souhaitées dans les champs *Presque plein* et *Plein*, puis sélectionnez *Enregistrer*.
+

NOTE: Vous pouvez rétablir les valeurs de seuil aux valeurs par défaut recommandées : 80 pour *Presque plein* et 90 pour *Plein*.
