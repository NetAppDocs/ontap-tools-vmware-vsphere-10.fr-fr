= Console de maintenance des outils ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La console de maintenance des ONTAP tools for VMware vSphere vous permet de gérer les paramètres des applications, du système et du réseau.  Vous pouvez mettre à jour les mots de passe d'administrateur et de maintenance, générer des packages de support, configurer les niveaux de journalisation, gérer les paramètres TLS et activer les diagnostics à distance.

Après le déploiement des ONTAP tools for VMware vSphere, si la console de maintenance est inaccessible, installez VMware Tools depuis le serveur vCenter. Connectez-vous en utilisant le nom d'utilisateur  `maint` et le mot de passe définis lors du déploiement. Utilisez *nano* pour modifier les fichiers dans la console de maintenance ou la console de connexion root.


NOTE: Définissez un mot de passe pour l `diag`utilisateur lorsque vous activez les diagnostics à distance.

Utilisez l'onglet *Summary* de vos ONTAP tools for VMware vSphere pour accéder à la console de maintenance. Sélectionnez image:../media/launch-maintenance-console.gif["Bouton de lecture"] pour démarrer la console de maintenance.
