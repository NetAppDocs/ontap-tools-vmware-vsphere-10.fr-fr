= Vues de stockage ONTAP pour les banques de données dans ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP tools for VMware vSphere affiche les détails côté ONTAP des datastores et de leurs volumes dans l’onglet *Configurer*, y compris les détails du stockage backend, de l’agrégat et du volume pour chaque type de datastore.

.Étapes
. Dans l'inventaire du client vSphere, sélectionnez le datastore.
. Sélectionnez l'onglet *configurer* dans le volet de droite.
. Sélectionnez * Outils NetApp ONTAP * > * Stockage ONTAP *. L'affichage varie selon le type de base de données.  Voir le tableau ci-dessous :


|===


| *Type de datastore* | *Information disponible* 


| datastore NFS | La page *Détails du stockage* contient des informations sur le stockage backend, les agrégats et les volumes. La page *Détails NFS* contient des données relatives à la banque de données NFS. Remarque : si la valeur nconnect est modifiée en dehors des ONTAP tools, la valeur affichée dans ONTAP tools peut ne pas refléter cette modification externe. 


| Datastores VMFS | La page *Détails du stockage* contient des informations sur le système de stockage, les agrégats, les volumes et les zones de disponibilité du stockage (SAZ). La page *Détails de l'unité de stockage* contient des détails sur l'unité de stockage. 


| Datastores vVols | La page répertorie tous les volumes. Vous pouvez étendre ou supprimer du stockage depuis le panneau de stockage ONTAP. ONTAP tools for VMware vSphere ne prend pas en charge cette vue pour les datastores vVols basés sur le système ASA r2. 
|===
.Résultat
Vous pouvez consulter les détails de la banque de données côté ONTAP en fonction du type de datastore sélectionné.
