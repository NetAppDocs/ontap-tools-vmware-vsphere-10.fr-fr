= Vues de stockage ONTAP pour les banques de données dans ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Utilisez la page ONTAP Storage dans l'onglet *Configurer* pour afficher les informations sur la banque de données et le volume.

.Étapes
. Dans l'inventaire du client vSphere, sélectionnez le datastore.
. Sélectionnez l'onglet *configurer* dans le volet de droite.
. Sélectionnez * Outils NetApp ONTAP * > * Stockage ONTAP *. L'affichage varie selon le type de base de données.  Voir le tableau ci-dessous :


|===


| *Type de datastore* | *Information disponible* 


| datastores NFS | La page *Détails du stockage* contient des systèmes de stockage, des agrégats et des informations sur les volumes. La page *Détails NFS* contient des données relatives à la banque de données NFS. Remarque : si la valeur nconnect est modifiée en dehors des ONTAP tools, la valeur affichée dans ONTAP tools peut ne pas refléter cette modification externe. 


| Datastores VMFS | La page *Détails du stockage* contient des informations sur le backend de stockage, les agrégats, les volumes et les zones de disponibilité du stockage (SAZ). La page *Détails de l'unité de stockage* contient des informations sur l'unité de stockage. 


| Datastores vVols | Répertorie tous les volumes. Vous pouvez étendre ou supprimer du stockage à partir du volet de stockage ONTAP . Les outils ONTAP ne prennent pas en charge cette vue pour les datastores vVols basés sur le système ASA r2. 
|===
.Résultat
Vous pouvez consulter les détails de la banque de données côté ONTAP en fonction du type de datastore sélectionné.
