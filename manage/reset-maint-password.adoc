= Réinitialiser le mot de passe de la console de maintenance des ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Lors du redémarrage du système d'exploitation invité, le menu GRUB propose une option pour réinitialiser le mot de passe de l'utilisateur de la console de maintenance. Utilisez cette option pour mettre à jour le mot de passe de l'utilisateur de la console de maintenance sur la machine virtuelle. Après avoir réinitialisé le mot de passe, la machine virtuelle redémarre pour définir le nouveau mot de passe. Dans un déploiement haute disponibilité, le système met automatiquement à jour le mot de passe sur les deux autres machines virtuelles après le redémarrage de la machine virtuelle.


NOTE: Pour un déploiement HA de ONTAP tools pour VMware vSphere, modifiez le mot de passe de l'utilisateur de la console de maintenance sur le nœud de gestion ONTAP tools (node1).

.Étapes
. Connectez-vous à votre serveur vCenter
. Faites un clic droit sur la machine virtuelle et sélectionnez *Alimentation* > *Redémarrer le système d'exploitation invité*. Lors du redémarrage du système, l'écran suivant s'affiche : image:../media/maint-console-password.png["Réinitialiser le mot de passe de l'utilisateur de maintenance"]
+
Vous avez cinq secondes pour choisir votre option. Appuyez sur n'importe quelle touche pour interrompre le processus et figer le menu GRUB.

. Sélectionnez l'option *Réinitialiser le mot de passe de l'utilisateur de maintenance*. La console de maintenance s'ouvre.
. Dans la console, saisissez et confirmez le nouveau mot de passe.  Vous avez trois tentatives.  Le système redémarre après la saisie correcte du nouveau mot de passe.
. Appuyez sur *Entrée* pour continuer.  Le système met à jour le mot de passe sur la machine virtuelle.



NOTE: Le même menu GRUB s'affiche au démarrage de la machine virtuelle. Cependant, vous devez utiliser l'option de réinitialisation du mot de passe uniquement avec l'option *Redémarrer le système d'exploitation invité*.
