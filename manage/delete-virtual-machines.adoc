= Nettoyer les configurations VASA dans ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Suivez ces étapes pour effectuer le nettoyage VASA dans ONTAP tools.


NOTE: Supprimez tous les datastores vVols avant de commencer le nettoyage VASA.

.Étapes
. Ouvrez  `\https://OTV_IP:8143/Register.html` pour désenregistrer le plug-in.
. Vérifiez que le plug-in n'est plus disponible sur vCenter Server.
. Arrêtez la machine virtuelle (VM) ONTAP tools for VMware vSphere.
. Supprimez les outils ONTAP pour VMware vSphere VM.
