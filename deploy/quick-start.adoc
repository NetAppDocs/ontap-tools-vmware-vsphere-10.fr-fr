= Démarrage rapide des outils ONTAP pour VMware vSphere
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Configurez les outils ONTAP pour VMware vSphere avec ce guide de démarrage rapide.

Commencez par effectuer ces tâches essentielles pour rendre les outils ONTAP opérationnels lors de la configuration et du provisionnement initiaux. Ensuite, effectuez les tâches optionnelles en fonction de votre environnement et de vos exigences en matière de protection.

Dans un premier temps, vous déployez ONTAP tools for VMware vSphere sous la forme d'une configuration extra-small (XS) à nœud unique fournissant les services de base pour les datastores NFS et VMFS. Si vous avez besoin de conteneurs supplémentaires par service, d'une résilience accrue, ou de datastores vVols et de haute disponibilité (HA), complétez d'abord ce workflow, puis poursuivez avec l'extension. Pour plus d'informations, consultez la link:../deploy/ha-workflow.html["Workflow de déploiement de la HAUTE DISPONIBILITÉ"].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Une seule"] Planification du déploiement
[role="quick-margin-para"]
Confirmez que votre environnement est prêt pour un déploiement pris en charge. Vérifiez que vos versions de vSphere, d'ONTAP et d'hôte ESXi sont compatibles avec la version des ONTAP tools. Allouez suffisamment de CPU, de mémoire et d'espace disque. Selon vos règles de sécurité, vous devrez peut-être configurer des pare-feu ou d'autres contrôles de sécurité pour autoriser le trafic réseau.

[role="quick-margin-para"]
Assurez-vous que le serveur vCenter est installé et accessible.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Deux"] Déployez les outils ONTAP pour VMware vSphere
[role="quick-margin-para"]
Déployez l'appliance ONTAP tools pour établir les services de base pour les datastores NFS et VMFS.

[role="quick-margin-para"]
Si vous prévoyez d'étendre votre déploiement pour les datastores vVols et la haute disponibilité (HA), complétez d'abord ce workflow. Dans ONTAP tools for VMware vSphere 10.6, l'ajout à chaud de CPU et le hot-plug de mémoire sont activés par défaut.

[role="quick-margin-para"]
Lors du déploiement, examinez attentivement les champs *Personnaliser le modèle*, en particulier le nom de l'hôte, l'utilisation de l'adresse IP des ONTAP tools et les exigences DNS.

[role="quick-margin-list"]
* link:../deploy/ontap-tools-deployment.html["Déployez les outils ONTAP pour VMware vSphere"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Trois"]Enregistrez et installez le plug-in client vCenter
[role="quick-margin-para"]
Ajoutez une instance de serveur vCenter pour enregistrer le plug-in client vCenter et appliquer les privilèges et rôles requis. Lorsque vous ajoutez une instance de serveur vCenter, ONTAP tools enregistre le plug-in distant, applique les privilèges personnalisés du plug-in et de l'API, crée des rôles personnalisés et ajoute un raccourci vers le plug-in dans l'interface utilisateur vSphere.

[role="quick-margin-list"]
* link:../configure/add-vcenter.html["Ajouter des instances vCenter Server aux outils ONTAP"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Quatre"]Configurer les backends de stockage
[role="quick-margin-para"]
Connectez les ressources de stockage ONTAP afin que les outils ONTAP puissent provisionner et gérer les datastores. Ajoutez un backend de stockage à un cluster ONTAP. Dans les environnements multitenants où un serveur vCenter est associé à une SVM locataire, utilisez ONTAP tools Manager pour ajouter le cluster. Associez ensuite le backend de stockage au serveur vCenter afin de créer un mappage global pour cette instance vCenter.

[role="quick-margin-para"]
Ajoutez des backends de stockage locaux avec des identifiants de cluster ou de SVM en utilisant l’interface des outils ONTAP. Ces backends de stockage sont limités à un seul vCenter. Lorsque vous utilisez des identifiants de cluster localement, les SVM associés sont automatiquement mappés au vCenter pour la gestion vVol ou VMFS. Pour la gestion VMFS, y compris SRA, les outils ONTAP prennent en charge les identifiants de SVM sans nécessiter de cluster global.

[role="quick-margin-list"]
* link:../configure/add-storage-backend.html["Ajout d'un système back-end"]
* link:../configure/associate-storage-backend.html["Associez le back-end de stockage à une instance vCenter Server"]

[role="quick-margin-list"]
* link:../manage/enable-services.html["Activez les outils ONTAP pour les services VMware vSphere"]

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Quatre"] Activer la protection de synchronisation active SnapMirror
[role="quick-margin-para"]

[role="quick-margin-para"]
Mettez en place une stratégie de sauvegarde et de restauration pour protéger la configuration des ONTAP tools et récupérer rapidement en cas de panne.

[role="quick-margin-para"]
La sauvegarde est activée par défaut dans ONTAP tools for VMware vSphere 10.6 et s'exécute toutes les 10 minutes.
